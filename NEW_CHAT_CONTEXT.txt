Resumo Tecnico Completo (cole no novo chat)

1) Contexto e direcao do projeto
- Projeto: HR Na Chapa (hamburgueria).
- Objetivo Fase 1: site de delivery + painel admin + estoque por insumos + pedidos + promocoes + WhatsApp.
- Direcao de design escolhida para o site: rustico artesanal, tom premium, mobile-first.
- Documento de bussola criado: AI_CONTEXT.md (stack, estrutura, filosofia e checklist de retomada).

2) Stack e arquitetura
- Frontend: Angular 21 standalone + Tailwind v3.
- Backend: NestJS 11 + TypeORM + PostgreSQL 16 + JWT/roles.
- Infra: docker-compose.yml com postgres + frontend.
- Banco controlado por migration (backend/src/database/migrations/*).
- Backend modular por dominio (auth, categories, ingredients, products, product-ingredients, product-extras, orders).

3.3 Pedidos e baixa de estoque
- Pedidos implementados com itens, status e calculo de totais.
- Transicao de status validada por maquina de estados.
- Ao confirmar (status=confirmed), baixa automatica de estoque por receita com transacao (all-or-nothing).
- Arquivos principais:
  - backend/src/orders/*
  - Entidades:
    - backend/src/entities/order.entity.ts
    - backend/src/entities/order-item.entity.ts
- Rotas:
  - POST /orders
  - GET /orders
  - GET /orders/:id
  - PATCH /orders/:id/status
- Status suportados:
  - new, confirmed, in_preparation, ready, out_for_delivery, delivered, canceled.

11) Comandos para retomada rapida
- Banco:
  - docker compose up -d postgres
- Backend:
  - cd backend
  - npm install
  - npm run migration:run
  - npm run start:dev
- Frontend:
  - cd hrnachapa-app
  - npm install
  - npm start
- Endpoints basicos:
  - GET http://localhost:3000/health
  - POST http://localhost:3000/auth/login
